# Z1RON Portfolio

`z1ron.com` 的個人研究作品集第一版，內容已依李子榕的履歷整理為公開網站版本。

## 啟動

```bash
npm install
npm run dev
```

正式輸出：

```bash
npm run build
```

GitHub 與 Cloudflare Pages 自動部署設定請見 [DEPLOYMENT.md](./DEPLOYMENT.md)。

Production SEO、routing、accessibility 與效能檢查請見 [SEO-AUDIT.md](./SEO-AUDIT.md)。

## 下一階段可補資料

- 專題研究的架構圖、成果數據、程式碼或論文摘要
- GitHub、LinkedIn 與其他公開社群連結
- 想公開的履歷 PDF（目前未放入，以免直接公開電話與生日）
- 英文版內容

## 設計方向

- 編輯感大字排版，搭配溫暖紙色與電光藍綠點綴
- 滾動進場、跑馬燈、磁吸按鈕、卡片視差等微互動
- 滑鼠、鍵盤與觸控皆有操作回饋
- 響應式版面與 `prefers-reduced-motion` 無障礙支援
